# CCR Project – CAD Components

This folder contains 3D CAD STEP files used in the **CCR (Collaborative Crossing Readiness)** project. These components are essential for building and assembling the physical modules involved in the project’s traffic light and sensor systems.

## Included Files

### 1. `3 Light Traffic Light All Parts.step`
A full 3D assembly of the **3-LED Combined Traffic Light**, including:
- Housing
- Internal LED holders
- Cable interface slots

This version is typically used for full-color signaling in crossings.

---

### 2. `2 Light Traffic Light All Parts.step`
A complete 3D model of the **2-LED Combined Traffic Light**, ideal for simpler applications where only "Go" and "Stop" indicators are needed. Includes:
- Dual-lens enclosure
- Mounting interface
- Cable routing support

---

### 3. `Mountable - Aluminium Mount Plate.step`
A **universal mounting base** that supports both 2-LED and 3-LED traffic lights. Designed to be:
- Floor or roof mountable
- Durable with aluminium structure
- Compatible with bolt or clamp systems

---

### 4. `Connector TypeC.step`
A 3D model of an **off-the-shelf USB Type-C connector** used in the enclosures for interfacing. It enables:
- Standard Type-C cable connection
- Power and data interface to traffic light logic modules
- Easy replacement in the field

---

## Usage
These components are part of the **hardware design phase** of the CCR project. They can be used for:
- Rapid prototyping
- Mechanical fit checks
- Manufacturing references
- Assembly documentation

## Notes
- All files are in STEP format (.step) and suitable for most CAD platforms like SolidWorks, Fusion 360, and Onshape.
- Dimensions follow the metric system (mm).
- Models are organized for easy integration in larger assemblies.

---

## Project Context
The **CCR Project** aims to develop smart infrastructure for enhancing pedestrian safety using visual signals, BLE connectivity, and AI logic modules. These CAD files contribute to the physical design of modular traffic lights used in intersections and crossings.
